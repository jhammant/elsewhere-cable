# Generated fictional background plates

These original, reusable 16:9 background plates were generated with OpenAI ImageGen for
Elsewhere Cable. They contain no real people, brands, readable copy, or external source media.
The renderer selects a compatible plate by visual medium and then prefers premise/tag matches.
Procedural 2D scenery remains the fallback.

## midnight-signal-newsroom-v1

An editorial paper-collage municipal newsroom inside a midnight railway signal box.

## boring-community-hall-v1

A deliberately ordinary hand-painted community-hall refreshment room for slow, awkward scenes.

## cosmic-orange-kitchen-v1

A bright cel-painted kitchen inside an orange moon for visually loud surreal scenes.

## aquarium-discount-studio-v1

A fluorescent xerox-punk shopping studio inside an abandoned aquarium.
